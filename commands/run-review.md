# Run a bounded review

Read company context and the job contract. Inspect one permitted sample. Run the deterministic example using the approved model and an explicit as-of date. Review the reasons, missing facts and exclusions.

Prepare a decision record with question, observation, one proposed change, comparison, maturity, limit, hold condition, owner and review date. Keep the record in private working memory. A recommendation is not authorization to send, publish or write live systems.
