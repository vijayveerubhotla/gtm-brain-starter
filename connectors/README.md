# Connector contract

No connector or credential is shipped with this starter. Name the system, purpose, permitted fields, access scope and responsible owner before adding one.

Keep secrets in an approved runtime secret store, never this repository. Begin read-only. For writes, define stable event IDs, field ownership, retries, suppression and rollback. Test on an approved sample and record the accepted receipt.
